# 🤖 BERT FAQ Chatbot

A Question Answering chatbot built using Google's BERT model through Hugging Face Transformers.

## 📖 Project Overview

This project demonstrates how to build an AI-powered FAQ chatbot using a pre-trained BERT model. The chatbot answers questions by searching through a given context and extracting the most relevant answer.

## ✨ Features

- BERT-based Question Answering
- Uses Hugging Face Transformers
- Extractive Question Answering
- Easy to customize with your own knowledge base

## 🛠 Technologies Used

- Python
- Jupyter Notebook
- Hugging Face Transformers
- PyTorch

## 📂 Repository Contents

- `BERT Model FaqBot.ipynb` – Main notebook containing the chatbot implementation.
